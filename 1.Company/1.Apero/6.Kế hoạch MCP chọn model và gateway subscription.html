Ràng buộc của Claude Code

Đối chiếu tài liệu tại code.claude.com, mục hooks và model config, lúc lập kế hoạch:

  • Model phiên đặt bằng claude --model, ANTHROPIC_MODEL, hoặc trường model trong settings. Trong phiên thì đổi bằng /model. SDK đổi bằng set_model.
  • Hook UserPromptSubmit chạy trước khi model trả lời, nhưng chỉ thêm additionalContext. Hook này không sửa prompt và không gán model.
  • Hook PreToolUse sửa tham số tool qua updatedInput. Tool Agent có trường model: haiku, sonnet, opus, fable.
  • Hook PreModelSwitch nhận prompt_cache_warm, context_tokens, cache_ttl và estimated_cache_write_usd. Nó cho qua, chặn, hoặc hỏi. Nó không bịa một model mới.
  • /usage của Pro và Max hiện thanh hạn mức gói. Số đô la trên màn đó là cho tài khoản API.
MCP chấm prompt trước. Phiên mới mang sẵn --model. Phiên đang chạy giữ model khi cache còn ấm. Subagent được sửa trường model trước khi tool chạy.

Kiến trúc

Ba phần, một sổ. Gateway phục vụ đúng người đang ngồi máy và dùng seat của người đó. Không gom nhiều subscription thành một khóa API, không đọc cookie web để giả làm API.

1. MCP apero-route chấm bậc bằng bảng quy tắc. Vòng 1 không gọi model để chấm.
2. Gateway nhìn bậc và hạn mức seat, rồi trả provider cùng hành động: mở mới, giữ, hỏi, hoặc dừng.
3. Lệnh bọc apero mở claude --model. Ba hook gắn lớp quyết định vào Claude Code.
4. Claude Code trả lời. Sổ ghi bậc, provider, model và token.

Thang độ khó

Đầu vào: prompt, file_count, wants_tests, pasted_file, estimated_input_tokens, user_override, caller là interactive hoặc product.

Token vòng 1 ước lượng bằng độ dài ký tự chia 4, cộng kích thước file được nhắc trong repo đang mở. Số này để chọn bậc, chưa phải số nhà cung cấp tính tiền. Xét từ trên xuống, gặp bậc thì dừng.

BậcKhi nàoModel
D0Đổi tên, regex, format, typo, lọc một đoạn log. Không quá 1 file. Không yêu cầu test. Input ước lượng dưới 8.000 token.haiku
D1Sửa một việc trong 1 hoặc 2 file. Không có thiết kế, migration, hay rà soát cả hệ thống.sonnet
D2Từ 3 file, hoặc có yêu cầu test, hoặc vòng sửa kèm lệnh kiểm tra.sonnet
D3Thiết kế, migration, lỗi chưa tái hiện được, hoặc từ 8 file.opus
D4Người dùng ghi rõ việc then chốt hoặc rà soát bảo mật, và prompt đã ở D3.fable nếu còn hạn mức, không thì opus

user_override được ghi sổ. Gateway vẫn chặn Fable khi hết phần weekly, và vẫn nâng Haiku lên Sonnet khi ước lượng input vượt 100.000 token, lý do haiku_price_cliff. Vượt mốc đó, Haiku 5.5 tính input $0,50 và output $2,50 cho một triệu token.

Prompt tiếng Việt chưa có benchmark công khai trong báo cáo repo. Quy tắc đọc từ khóa tiếng Việt và tiếng Anh. Sau bốn tuần sổ mới xét bộ chấm nhỏ, nếu quy tắc gán sai trên prompt thật của nhóm.

Luật provider

Caller product nhận api_product. Đường đó bật prompt caching. Việc không cần trả lời ngay đi Batch API, giảm 50% input và output. Fast mode không dùng trên đường tiết kiệm. Sàn model dùng cùng bảng bậc.

Thứ tựProvider cho interactiveKhi nào
1copilot_subscriptionD0 và seat Copilot còn credit chat hoặc agent. Completion trong editor ở lại Copilot.
2claude_subscriptionD1–D3, hoặc D0 khi Copilot hết phần agent, và hạn mức tuần Claude còn dưới 70%.
3codex_subscriptionViệc code, hạn mức tuần Claude từ 70%, cửa sổ Codex trên Plus hoặc Pro của người đó còn.
4DừngHết quỹ subscription cho việc code. Không tự chuyển sang khóa API.

D4 chỉ ở claude_subscription, trên seat Max còn phần Fable, tối đa một nửa hạn mức tuần. Hết thì xuống Opus trên cùng seat.

Ngưỡng 70% là ngưỡng vận hành, chưa phải số nhà cung cấp. Bốn tuần đầu ghi tỷ lệ dùng thật rồi mới siết hoặc nới. Một seat Claude là một quỹ cho Web, Desktop và CLI. Gateway không tạo ba quỹ.

Có ANTHROPIC_API_KEY trên lượt interactive thì gateway trả stop với lý do api_key_would_bill. Người chạy bỏ khóa khỏi môi trường phiên đó và dùng claude /login. Extra usage chỉ khi chủ seat đã bật, ghi auth_mode = extra_usage, tính như giá API. Credit API $100 hoặc $200 của Max không phải tiền trả cho lượt Claude Code.

Phiên giữ provider và model đến /clear hoặc hết phiên 5 giờ. Prompt mới vẫn được chấm lại:

  • Cùng model: giữ. Hook chỉ gắn thẻ bậc.
  • Muốn model rẻ hơn: giữ model hiện tại. Hạ model cũng làm cache miss.
  • Muốn model đắt hơn lúc cache còn ấm: PreModelSwitch trả ask, kèm số đô la cache ước tính. Từ chối thì giữ model cũ.
  • Cache đã nguội, hoặc chưa có lượt nào: lên model đúng bậc, không hỏi.

/loop và scheduled task gửi lại cả cuộc trò chuyện theo chu kỳ, nên không nằm ở đường tiết kiệm. Prompt yêu cầu lặp mà không có điều kiện dừng thì MCP gắn repeat_risk.

Hợp đồng

JSON trên 127.0.0.1. Vòng 1 chỉ nhận kết nối từ máy đó.

POST /v1/classify

{
  "prompt": "đổi tên hàm parseDate cho đúng camelCase",
  "file_count": 1,
  "wants_tests": false,
  "pasted_file": false,
  "estimated_input_tokens": 900,
  "user_override": "",
  "caller": "interactive"
}

Trả về band, model, reasons. Ví dụ D0, haiku, vì đổi tên, một file, input ngắn.

POST /v1/route

Nhận session_id, kết quả classify, model hiện tại, cache_warm, context_tokens, và seat: phần tuần Claude đã dùng, Codex còn cửa sổ hay không, Copilot còn credit agent hay không, phần Fable đã dùng, tên plan.

actionÝ nghĩa
startPhiên mới. Lệnh bọc chạy claude --model với provider đã chọn.
keepGiữ model và provider hiện tại.
ask_switchMuốn lên model lúc cache ấm. Hook để Claude Code hỏi.
stopHết quỹ subscription phù hợp, hoặc đang có khóa API trên lượt interactive.

Ba tool MCP cùng schema: classify_prompt, route_session, quota_snapshot. File hạn mức do người chạy ghi sau khi xem /usage, Settings → Usage, và hạn mức Codex. Các PDF không có API công khai cho phần trăm còn lại của mọi gói. Thiếu file thì bốn tuần đầu gateway coi Claude còn dưới 70% và gắn quota_unmeasured. Sau đó, thiếu file thì route trả stop với lý do quota_required.

Gắn vào Claude Code

  1. Lệnh bọc apero. Gọi classify rồi route. start thì chạy Claude Code với --model trong môi trường không còn ANTHROPIC_API_KEY. stop thì in lý do và không mở phiên.
  2. UserPromptSubmit. Chấm lại trước khi trả lời. keep thì thêm context dưới 500 ký tự: bậc, model, provider, một lý do. Không dán lại prompt. Việc hỏi người dùng khi lên model nằm ở PreModelSwitch.
  3. PreToolUse trên Agent. Chấm prompt của subagent và ghi updatedInput.model. Đọc log, tìm file, regex thì haiku. Sửa nhiều file thì sonnet. Vòng 1 không đặt fable cho subagent. Subagent vẫn tốn hạn mức.
  4. PreModelSwitch. to_model đắt hơn model đã gán, và cache còn ấm, thì ask kèm estimated_cache_write_usd. /model fable khi gateway không cho D4 thì deny. Cưỡng bức chỉ qua user_override khi seat còn phần Fable.
  5. Một session, một việc. Đổi việc thì /clear. Câu phụ dùng /btw để khỏi vào history. Nêu đường dẫn và tên hàm, không dán cả file.

Sổ và lộ trình

Mỗi lượt một dòng JSONL: thời điểm, session, caller, bậc, lý do, model, provider, auth mode, action, input mới, cache read, cache write, output, đô la API niêm yết của lượt, và việc có được nhận hay không. Phí gói ghi một lần mỗi tháng cho mỗi seat. Hiệu suất tháng bằng tổng đô la API của các lượt đã nhận chia cho phí seat. Ba loại credit ở ba cột.

  1. Bộ chấm. 12 prompt mẫu: 3 D0 tiếng Việt, 3 D1, 2 D2 có test, 2 D3, 1 D4, 1 Haiku vượt 100.000 token. Cùng prompt hai lần ra cùng JSON.
  2. MCP stdio. Ba tool. Test bằng JSON, chưa cần mở Claude Code. classify_prompt khớp 12 mẫu.
  3. Gateway Claude. Tuần 40% ra subscription Claude. Tuần 80% và Codex còn cửa sổ thì sang Codex. Có khóa API trên interactive thì dừng. Caller product ra API dù seat Claude còn trống.
  4. Hook và lệnh bọc. JSON stdin, không cần mạng. Agent lọc log bị đổi từ opus xuống haiku. PreModelSwitch trả ask khi cache ấm và model đích đắt hơn. Lệnh bọc in claude --model sonnet ở ca D1 và không mở tiến trình ở ca stop.
  5. Copilot và Codex. Test chỉ kiểm quyết định, chưa gửi prompt đi. D0 vào Copilot khi còn credit agent. Việc code sang Codex khi Claude từ 70%. Fable bị chặn từ 50% weekly trên Max, và bị chặn trên Pro.
  6. Một tuần dùng thật. Năm việc: sửa một file, đọc log, viết báo cáo, gọi API sản phẩm, hỏi ngắn. Cuối tuần đủ bốn số: phí gói cộng hóa đơn API, đô la API của việc đã nhận, tỷ lệ cache read trên input lặp, tiền cho mỗi việc được nhận.
Nâng Claude Max hoặc ChatGPT Pro 100/200/500 chỉ sau bốn tuần sổ của nhóm, khi giá trị API của phần dùng được lớn hơn phần phí tăng. Hạn mức tuần còn thừa thì giữ gói hiện tại.
